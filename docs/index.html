ONE MODEL · 5 SPECIALIZED PROMPTS

One Qwen.
5 Careful Roles.

01

Schema Agent

Maps every source column to a clear canonical schema.

02

Structured Agent

Normalizes phones, emails, dates, IDs, and booleans.

03

Category Agent

Unifies equivalent majors, skills, roles, and tools.

04

Text Agent

Removes noise while preserving the original meaning.

05

Validation Agent

Flags missing, malformed, duplicate, and uncertain data.

LIMITED ADAPTIVE AUTHORITY

It Can Notice What You Didn’t Hard-Code.

The guarded planner studies privacy-preserving structural patterns, composes allowlisted cleanup operations, and previews their effect. Safe mechanical fixes can run automatically; semantic guesses and deletion requests stay review-only.

Auto-Apply

High-confidence, low-risk formatting fixes with a complete before/after audit.

Ask for Review

Ambiguous meanings, identity changes, large edits, and all row-removal proposals.

Never Allowed

Arbitrary code, filesystem access, invented personal information, or source overwrites.

PRIVACY BY DESIGN

Your Data Stays Yours.

Qwen runs on your own computer. Direct identifiers are masked before inference, the model has no filesystem tools, and original files are never modified.

✓ Localhost only

✓ Reversible masking

✓ Auditable reports
